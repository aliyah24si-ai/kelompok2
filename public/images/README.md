# Logo Instructions

## Untuk menampilkan logo di dashboard:

1. **Upload file logo** dengan nama: `logo-perangkat-lembaga.png`
2. **Letakkan di folder**: `public/images/`
3. **Format yang disarankan**: PNG dengan background transparan
4. **Ukuran yang disarankan**: 200x200 pixel atau rasio 1:1
5. **Ukuran file maksimal**: 500KB untuk performa optimal

## Path lengkap file logo:
```
kelompok2/public/images/logo-perangkat-lembaga.png
```

## Saat hosting:
- Pastikan folder `public/images/` dan file logo terupload
- Periksa permission folder (755) dan file (644)
- Jika logo tidak muncul, cek apakah file ada di path yang benar

## Fallback:
Jika file logo tidak ada, logo akan otomatis disembunyikan tanpa error.
